加权（仓权）合约监控面板 · 单文件 EXE 使用说明
============================================================
产物：发布\加权合约监控面板.exe      体积约 90 MB
python -m PyInstaller 打包，内置全部 Python 依赖（含 tqsdk / pandas / numpy / scipy）
============================================================

一、怎么运行
  1) 双击「加权合约监控面板.exe」，会弹出一个黑色控制台窗口（显示日志）。
     · 单文件 EXE 需要先自解压，双击后约 5~10 秒才出现控制台窗口，属正常现象。
  2) 启动后自动打开浏览器，地址默认 http://127.0.0.1:8689
     · 端口被占用时会自动改用 8690、8691…，以控制台里打印的地址为准。
     · 首次启动需 20~60 秒预热（拉取全部品种历史日K），预热完再刷新即可。
  3) 关闭：直接关掉控制台窗口，或在窗口内按 Ctrl+C。

二、首次使用
  · 默认数据源 = 曲合网（免账号、免密钥，82 个品种，日K 约 3.5 年）→ 双击就有数据。
  · 想用天勤（87 个品种、日K 10 年+、分钟K 4000 根、推送式实时）：
      ⚙️ 设置 → 数据源 → 填「快期账号 / 密码」→ 保存 → 顶栏切到「天勤（TqSdk）」。

三、配置与数据放在哪（重要）
  都写在 **EXE 同级的「缓存」目录**里，所以 EXE 拷到哪、配置就跟到哪：

    缓存\配置.json         面板设置、数据源、天勤账号、邮件参数
    缓存\阈值设置.json      各品种上阈 / 下阈 / 锁定状态
    缓存\曲合日K缓存.json   曲合源日K缓存（可删，会自动重建）

  ★ EXE 本体不含任何账号信息，可以放心分享。
  ★ 想直接复用本项目里已经配好的天勤账号与阈值：
      把「加权合约监控面板.exe」复制到本目录（与 服务端.py 同级）再双击即可；
      或把本目录的「缓存」文件夹复制到 发布\ 下面。

四、常见问题
  · 浏览器没自动打开 → 手动访问控制台里打印的地址。
  · 面板一直显示“预热中” → 天勤源首次连接较慢（30~60 秒），再等一会儿并刷新。
  · 天勤提示“tqsdk 不可用” → 设置面板里没填账号；只想要数据就切回「曲合网」。
  · 杀毒软件报毒 → PyInstaller 单文件 EXE 的常见误报，加入信任即可
    （源码就在同目录，可自行执行「打包exe.py」核对重建）。
  · 想自己重新打包 → 在本目录执行：  C:\Python314\python.exe 打包exe.py
    （需要 Python 3.14 + pyinstaller + tqsdk；产物输出到 发布\）

五、邮件预警会不会刷屏
  不会。内置五层防轰炸：
    ① 边沿触发（只在“刚突破”的那一瞬间发一次，持续超阈不重发）
    ② 滞回复位（回落到阈值内一定比例才复位，可再次计次）
    ③ 仅交易时段发信（闭市 / 周末 / 节假日静默，开盘首轮补发一封）
    ④ 同品种同方向冷却 600 秒
    ⑤ 全局配额：每小时 6 封、每天 30 封（超出转排队）

六、运行环境
  Windows 10 / 11 64 位；无需安装 Python，无需联网下载依赖（首次连天勤需联网登录）。
