加权（仓权）合约监控面板

核心能力

围绕「找极端、设阈值、盯突破」这条主线

📉

偏离度排序

以历史均价为 0 基准，高低两侧各自归一化到 100%，越极端越靠前。

🎯

一键设阈

把上/下阈直接设成所选周期 MA 的动态均值（最后一根用实时价替代，每个 tick 都在变）。

📊

全量 K 线

一次取回该周期全部 K 线，本地切片缩放平移，滚轮到任意位置都不再请求。

⚡

实时分时

2 秒一档实时价驱动主面板；图表最后一根 K 线用实时价重绘。

🔌

双源热切换

顶栏下拉即切曲合 ↔ 天勤，切换后历史 H/L/M 自动按新源重算。

🛡

边沿触发＋滞回复位＋交易时段门禁＋冷却＋全局配额，一天不再 720 封。

快速开始

三种方式，任选其一

① 单文件 EXE

免安装 Python，双击即用。

  1. 下载 EXE
  2. 双击运行（自解压约 5~10 秒）
  3. 浏览器自动打开 127.0.0.1:8689

② 源码 · Windows

下载 源码 ZIP 解压后双击 启动看板.bat。

启动看板.bat

③ 源码 · 命令行

默认 8689 端口，可自定义。

python 服务端.py --no-browser
📌 启动顺序已优化：服务端先监听端口、再后台预热历史日K。打开即刻可访问，不会出现 ERR_CONNECTION_REFUSED；顶部「更新 / 耗时」随后自动补齐。
